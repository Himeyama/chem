# 化学反応ゲーム

原子や分子の玉を落として反応させ、より複雑な物質を作っていくブラウザゲームです。高校化学で登場する反応を題材にしています。

## 遊び方

- マウス移動 / タッチで落下位置を狙い、クリック / タップで玉を落とします。
- 反応する組み合わせの物質同士がぶつかると、新しい物質に変化します。
- 発熱反応ではスコアが加算され、吸熱反応では減点されます（1 kJ/mol = 1000 pt）。
- これ以上反応しない物質は、一定時間後に自動的に消えます。
- 玉が容器の上端を超えるとゲームオーバーです。

## 技術構成

ビルドツールなしの素の HTML / CSS / JavaScript で構成しています。

- 物理演算: [Matter.js](https://brm.io/matter-js/)（CDN経由）
- 数式表示: [KaTeX](https://katex.org/)（CDN経由）

## ローカルでの動作確認

`type="module"` を使用しているため、`file://` で直接開くとブラウザの制約で正しく動作しません。簡易HTTPサーバーを立ててアクセスしてください。

```
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開いてください。
